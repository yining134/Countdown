# 素材格式评估（决策记录）

最终决定：用户确认 v1 仅支持 PNG 精灵图 + JSON，详见皮肤格式。以下保留早期比较依据，原 GIF + 静态 PNG 建议已被替代。

## 结论

v1 支持动态 GIF 和静态 PNG。皮肤作者按需选择，每阶段只需一个文件，不要求两套素材。
PNG 精灵图、PNG 序列、APNG 和 WebP 暂不作为公开导入格式。

GIF 满足直接导入现成动画的需求；PNG 用于预览、占位和静态阶段，可保留完整透明度，静态显示不启动帧定时器。
两者统一由 ImageIO 解码成 AnimationAsset（frames、frameDurations、canvasSize）；单帧不调度动画，GIF 多帧按延迟播放。
文件类型根据实际内容校验，不只检查后缀；动态 PNG 应明确拒绝，避免被误认为普通静态 PNG。
