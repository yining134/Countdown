# 实现与验证

日期：2026-11-11。当前为可运行的第一版开发原型，尚未准备公开发行。

## 已实现

- SwiftPM 原生 macOS App、主窗口、菜单栏、透明悬浮 NSPanel。
- 点击开始、拖动窗口、悬停暂停／继续、重置与主窗口入口；组件大小和位置持久化。
- 默认 25 分钟与 1–1440 分钟自定义时长，单次倒计时；本轮状态持久化与到期恢复。
- PNG 精灵图、按进度切换阶段、完成循环动画；暂停／隐藏时停止组件动画。
- 皮肤库、删除、ZIP 选择、拖放入口、HTTPS ZIP 直链、取消、校验与导入失败清理。
- 可选完成音效，无系统通知、无完成弹窗、无数字时间展示。
- 自有几何像素占位图、可直接导入的 Examples/StarterSkin.zip、皮肤协议说明。
- 单一 script/build_and_run.sh 与 Codex Run 配置，资源打包和本机 ad-hoc 签名。

## 实际通过

- ./script/build_and_run.sh --verify：构建成功、组装并签名 App、启动进程存在。
- vtool 显示二进制 minos 14.0；当前构建机器为 arm64 macOS 26，尚未在真实 macOS 14 上运行。
- 原生 UI 实际操作：将时长设为 1 分钟，开始 → 暂停 → 继续 → 完成。
- 主窗口画面观察到种子、发芽与成长阶段切换。
- 关闭主窗口后，截图仍显示独立植物组件。
- 本地 StarterSkin.zip 导入成功、列表新增 Imported Sprout 并自动选中。
- 同 ID 重复导入提示错误，现有皮肤保留。
- 含 ../ 路径的临时 ZIP 被拒绝，未进入安装流程；临时异常包已移除。
- App 重新启动后加载已安装皮肤并恢复完成态。
- 用户时长已恢复 25 分钟；最终 UI 操作启动新一轮后，Mac 锁屏中断了重置验证。
- 构建脚本 bash 语法检查通过。
