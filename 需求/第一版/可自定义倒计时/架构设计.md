# Countdown 第一版架构

## 范围

macOS 14+、单计时器、默认 25 分钟、自定义 1–1440 分钟，无休息循环、账号、后端或系统通知。
透明悬浮组件可拖动、调整大小和记住位置，悬停提供暂停／继续、重置和主窗口入口。组件不展示数字时间。
完成动画持续循环，皮肤可选完成音效播放一次；主窗口管理 PNG 精灵图皮肤，通过本地 ZIP、拖放或 HTTPS ZIP 直链导入。
初次启动显示主窗口与组件，关闭主窗口后菜单栏和组件常驻，保留 Dock 入口。
正式树苗后续制作，当前使用代码绘制的几何像素占位图。

## 技术选择

Swift 5.9+、SwiftUI、Observation、少量 AppKit，SwiftPM 单 executable target，无第三方依赖。
ImageIO 解码静态 PNG，AVAudioPlayer 播放可选音效；ZIP 先解析中央目录及本地头，再使用系统 ditto 解压到隔离临时目录。
源码按职责拆分，不单独拆空模块，不为每个对象增加协议。

## 分层

```text
Sources/Countdown/
  App/        CountdownApp、AppDelegate、AppModel：装配、生命周期、用户动作
  Models/     CountdownSession、SkinManifest、Skin：数据与阶段选择
  Stores/     CountdownStore、SkinStore、PreferencesStore：计时、皮肤库、偏好
  Services/   SkinValidator、ZIPPreflight、SkinImporter、AnimationLoader、CompletionSoundPlayer
  Views/      MainWindow、FloatingWidget、SpriteView：主窗口与悬浮内容
  Platform/   FloatingPanelController、SpriteImageView：窗口和 AppKit 帧显示
  Resources/StarterSkin/：内置 PNG 图集与清单
Examples/StarterSkin/：面向皮肤作者的示例
script/：构建运行与占位素材绘制
.codex/environments/：Codex Run 动作
```

AppModel 持有各 Store、音效服务和唯一面板控制器。UI 与窗口操作在 MainActor；下载、解压、校验与图集解码在后台执行。
SwiftUI 只消费同一份计时与皮肤状态，AppKit 不保存第二份业务状态。

```text
组件／主窗口／菜单栏 → AppModel → CountdownStore
                                  ↓ 状态与进度
SkinStore 当前皮肤 → 动画名称选择 → SpriteView → SpriteCanvas
                                  ↓ 完成事件
                            CompletionSoundPlayer
```

## 计时

状态为 idle、running、paused、completed。idle／completed 点击开始新一轮；running 和 paused 通过悬停按钮切换；任意状态重置回 idle。
本轮保存 duration、deadline、pausedRemaining，剩余时间取 max(0, deadline-now)，不用 tick 次数累减。
仅运行时每 0.5 秒刷新；暂停、重置和完成后停止计时定时器。恢复唤醒时立即刷新。
进度 clamp(1-remaining/duration,0...1) 决定成长阶段；完成状态单独映射 completed 动画。

休眠继续计时，退出重开恢复；到期状态恢复时不补播声音。修改时长对下一轮或重置生效。
采用墙上时钟以支持跨进程恢复，手动修改系统时间会影响剩余时间，第一版接受这一限制。
状态转移时原子写入 Session.json，不按每次 tick 写磁盘。

## 窗口与交互

SwiftUI 主窗口及菜单栏；NSPanel 使用 borderless、nonactivatingPanel、透明背景、无阴影、floating level、hidesOnDeactivate=false。
collectionBehavior 使用 canJoinAllSpaces、fullScreenAuxiliary、stationary，目标是跨桌面置顶。
系统锁屏、安全界面和系统模态窗口不保证覆盖；其他应用全屏、Stage Manager 和多显示器仍需实际设备验证。

图像区域原生处理鼠标按下，移动超过 4 pt 后开始拖动，松开短点击触发开始；控制按钮不经过图像拖动区。
悬停按钮占固定 44 pt 高度，出现时不改变窗口边界；最小窗口宽度 112 pt，确保小尺寸植物的按钮仍可操作。
植物大小 64–256 pt，通过主窗口滑杆调整。保存全局坐标与尺寸，屏幕变化后将位置夹回可见范围；菜单栏与主窗口可找回组件。
窗口通过 SwiftUI 主场景的 openWindow 回调恢复主窗口，不依赖独立 NSHostingView 中的默认环境动作。

## 精灵图播放

仅支持静态 PNG 精灵图，JSON 定义连续帧范围与帧率。帧按从左到右、从上到下编号。
AnimationLoader 后台解码；SpriteCanvas 仅持有当前图集，按时长更新 CALayer 当前帧，禁用隐式过渡，采用最近邻缩放。
静态动画、暂停和隐藏组件时停止帧定时器；暂停保留当前帧，指定 paused 动画时改为该动画首帧。
主窗口预览与组件各自持有正在展示的图集，不预加载整个皮肤库。

## 导入与存储

本地 ZIP 或 URLSession 临时下载 → ZIPPreflight → 隔离目录解压 → SkinValidator → 同文件系统 moveItem 安装 → 更新皮肤列表。
下载使用 ephemeral session，限制超时与大小，只允许 HTTPS 重定向。ZIP 检查中央目录、本地头、路径、权限、压缩方法、条目数、声明大小和重叠区域。
解压过程监控展开大小与超时，结束后再检查文件类型与大小。取消和失败清理本次临时目录，未通过校验不进入皮肤库。
资源尺寸、动画引用、阶段次序、音频格式与时长均校验。具体限制见皮肤格式。
重复 ID 当前报错，先删除旧皮肤后再导入，避免隐式覆盖。

Application Support/local.countdown.app/Skins/<id>/ 存用户皮肤，Session.json 存本轮状态；UserDefaults 存时长、选择和窗口位置尺寸。
内置皮肤从应用包只读加载，缺失／损坏用户皮肤回退内置皮肤，并在主窗口显示加载警告。
无数据库。开发脚本组装 .app、复制资源、ad-hoc 签名并启动；分发签名、公证与正式图标留待发布阶段。
