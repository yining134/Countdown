# 皮肤格式 v1

最终方案：PNG 精灵图 + JSON，ZIP 导入。GIF、APNG、WebP、独立 PNG 序列暂不接受。

## 包结构

```text
skin.json
spritesheet.png
complete.wav       可选，也支持 MP3、M4A
```

ZIP 根目录直接放 skin.json，不增加包装文件夹。打包时排除 .DS_Store、__MACOSX；示例使用标准 ZIP Deflate。
示例：Examples/StarterSkin/skin.json，以及可直接导入的 Examples/StarterSkin.zip。

## 清单字段

| 字段 | 含义 |
| --- | --- |
| schemaVersion | 固定为 1 |
| id | 1–80 字符，小写字母／数字起始，可包含点和横线，不允许连续两个点 |
| name | 展示名称，1–80 字符 |
| author | 可选作者名 |
| spritesheet | PNG 图集相对路径 |
| frameSize.width / height | 单帧像素尺寸，1–512，建议 128×128 |
| animations | 动画名称到动画定义的字典，1–100 个 |
| animations.*.startFrame | 起始帧索引，从 0 开始 |
| animations.*.frameCount | 连续帧数量，1–300，不得超过图集边界 |
| animations.*.fps | 帧率，1–30，可为小数 |
| idle | 待机动画名称，必填 |
| stages | 1–100 个进度阶段 |
| stages[].from | 已完成比例，范围 [0,1)，第一项须为 0，严格递增 |
| stages[].animation | 阶段使用的动画名称 |
| paused | 可选暂停动画名称，暂停时显示它的首帧；缺省冻结当前画面 |
| completed | 完成动画名称，必填 |
| completionSound | 可选本地 WAV／MP3／M4A，0–10 秒内（不含 0） |

帧从左到右、从上到下编号，所有帧使用相同画布。未引用的图集单元不播放。
阶段区间为 [from, 下一项.from)，最后一段结束于 1；到达 100% 后使用 completed。
所有动画默认循环；frameCount 为 1 时不启动动画定时器。
待机、完成状态均可点击开始新一轮；暂停停止动画和计时，继续时恢复。
PNG 支持透明背景，按原比例居中，不裁切。像素素材使用最近邻缩放，建议所有帧的植物根部位置保持一致。

## 限制

- ZIP 最大 25 MiB，展开最大 100 MiB，最多 200 个条目。
- 仅支持单卷普通 ZIP，Store／Deflate，不支持 ZIP64、加密、链接和特殊文件。
- 图集必须为单张静态 PNG，单通道位深不超过 8，宽高不超过 8192，面积不超过 16,777,216 像素（约 64 MiB RGBA）。
- 图集宽高须分别是帧宽高的整数倍，所有动画帧必须位于图集内。
- skin.json 最大 64 KiB；未知普通字段忽略，未知 schemaVersion 拒绝。
- 路径采用包内相对路径，禁止绝对路径、..、反斜线、远程 URL、符号链接和越界引用。
- ZIP 不允许重复路径或大小写冲突，不执行包内代码。
- 同 ID 重复导入报错，现有皮肤保留；不提供隐式覆盖。

## 示例

```json
{
  "schemaVersion": 1,
  "id": "yourname.seed",
  "name": "Seed",
  "spritesheet": "spritesheet.png",
  "frameSize": { "width": 128, "height": 128 },
  "animations": {
    "seed": { "startFrame": 0, "frameCount": 4, "fps": 4 },
    "sprout": { "startFrame": 4, "frameCount": 4, "fps": 6 },
    "finish": { "startFrame": 8, "frameCount": 4, "fps": 8 }
  },
  "idle": "seed",
  "stages": [
    { "from": 0, "animation": "seed" },
    { "from": 0.5, "animation": "sprout" }
  ],
  "completed": "finish"
}
```

上述示例需要至少 12 个图集单元。音效可通过 completionSound 字段引用，省略则静音。
